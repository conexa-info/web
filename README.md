CONEXA
Agencia de creadores de contenido, desarrollo comercial y marketing de influencers.
Conexa conecta creadores de contenido, comercios locales y marcas para desarrollar colaboraciones comerciales auténticas. La propuesta combina gestión comercial, ideación creativa, producción y acompañamiento para campañas en redes sociales.
Características
- Inicio: presentación de Conexa y acceso a sus servicios.
- Servicios integrales: ideación y guion creativo, producción y locaciones, y desarrollo comercial 360°.
- Propuestas para marcas: formulario para describir una empresa, persona de contacto, tipo de colaboración e iniciativa.
- Quiénes somos: historia, filosofía y modelo de valor compartido entre comercios, creadores y marcas.
- Métricas de Spikiii: panel con métricas de audiencia y enlaces a sus redes sociales.
- Sumarte como creador: formulario de postulación para creadores de TikTok e Instagram.
- Contacto: acceso por correo electrónico y WhatsApp.
Tecnologías utilizadas
- HTML5 para la estructura.
- Tailwind CSS Browser para los estilos y el diseño adaptable.
- CSS para efectos visuales, fondos, tarjetas tipo glassmorphism y brillos.
- JavaScript para la navegación entre pestañas, desplazamiento suave, formularios y eventos de analítica.
- Google Fonts: Space Grotesk y Syne.
- Font Awesome para los iconos.
- Google Analytics 4 para medir eventos de navegación y conversiones.
Identidad visual
La interfaz utiliza un tema oscuro con acentos violeta neón (#280FC2), tipografía moderna, fondos texturizados y tarjetas translúcidas. El diseño incluye adaptaciones para pantallas móviles y de escritorio.
Cómo ejecutar el proyecto
1. Guardá el código de la página en un archivo llamado index.html.
2. Abrí index.html en un navegador moderno.
La página carga Tailwind CSS, Google Fonts y Font Awesome desde CDN, por lo que se necesita conexión a Internet para que esos recursos externos se visualicen correctamente.
Formularios y contacto
Propuestas comerciales
El formulario solicita:
- Comercio, marca o empresa.
- Nombre de contacto.
- Tipo de colaboración.
- Detalles de la iniciativa.
Al enviarlo, prepara un mensaje y abre WhatsApp para que el usuario pueda revisarlo y enviarlo.
Postulación de creadores
El formulario solicita:
- Nombre y apellido.
- Usuario principal de TikTok o Instagram.
- Nicho o temática.
- Enlace a una publicación destacada.
- Presentación del perfil.
Al enviarlo, prepara un mensaje de postulación y abre WhatsApp.
Importante: estos formularios no guardan los datos en una base de datos; generan un enlace a WhatsApp con el mensaje preparado. El envío depende de que la persona complete la acción en WhatsApp.
